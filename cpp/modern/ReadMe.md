# Modern C++ Parsers

The same wire formats read through a fluent surface: each field is its own type whose `get()`
returns a native C++ value, byteswapping and scaling as the wire demands.

Each protocol has its own directory, named for its identifier with the version as the last
segment — `Iex.IexEquities.Tops.IexTp.v1.64` becomes `iex/iexequities/tops/iextp/v1.64` —
matching the C++ namespace the code declares.

Within a protocol:

- `types/` — one header per field type
- `bitfields/` — flag types, each flag a named predicate
- `structs/` — packet and message headers
- `messages/` — one header per message, each carrying the `message_type` that selects it
- `iterators/` — the packet walker: `initialize(data, length)` then `next()` per message
- `definitions.hpp` — every header above in one include

The programs under `executables/` and the tests under `tests/` are written against these.
