# Classes C++ Libraries

Classical object oriented C++: each message is a class that owns its fields, decoded once
into members and from then on an ordinary object — copyable, comparable, printable, and
encoded back with every count, length and type code derived. An abstract `Message`, a
`Visitor` with one overridable `visit` per message, a `Factory`, and a `Packet` that walks
a whole datagram by the model's framing rules.

Each protocol has its own directory, named for its identifier with the version as the last
segment — `Iex.IexEquities.Tops.IexTp.v1.64` becomes `iex/iexequities/tops/iextp/v1.64` —
matching the C++ namespace the code declares.

Within a protocol:

- `common/` — the byte codec, `Decimal`, the errors, and how values print
- `enums/` — a scoped enum per coded field, with `to_string`
- `bitfields/` — a class per flag byte, a `bool` accessor per bit
- `structs/`, `groups/` — headers, composites, and repeating group entries
- `messages/` — `Message.hpp`, `UnknownMessage`, and one `.hpp`/`.cpp` pair per message
- `Visitor.hpp`, `Factory.hpp`, the packet class, and `definitions.hpp`

Each library is compiled as `classes_<protocol>` by the repository's `CMakeLists.txt`. The
dump program and the tests under `tests/binary/classes/` are written against these.
