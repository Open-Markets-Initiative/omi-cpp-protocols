# Delimited C++ Readers

Readers of delimited files: lines of fields, a csv's header row naming its columns and then its
data lines. A reader selects the layout variant whose header the file states exactly, and reads
each data line straight into typed C++ values, with no binary record between. Every trait a field
is read by (its scale, its epoch, its zone, its text standing for no value) is the model's own: a
model that leaves one unstated is refused rather than guessed at.

Each protocol has its own directory, named for its identifier with the version as the last
segment — `Iex.IexEquities.Tops.IexTp.v1.64` becomes `iex/iexequities/tops/iextp/v1.64` —
matching the C++ namespace the code declares.

Within a protocol:

- `Rows.hpp` — the reading: how the file's lines split, each layout variant's header, and its
  reading of a data line onto a row, a template over the row it reads onto
- `Row.hpp` — the model's data record as a plain C++ row: text as a `std::string_view` of the line
  (valid while the line is), an integer as `std::int64_t`, a decimal as the `std::int64_t` of its
  stated places, a date as days since 1970-01-01, a time of day as its count since midnight, and a
  field a line may leave empty as optional. A time of day counted from midnight in a zone the model
  states has `<field>_utc(day)`: the instant on a day, UTC Unix nanoseconds. The row prints as
  `name=value`, a time of day on a stream's print day (`out << calendar::on(day)`) as ISO 8601 UTC

Shared by every reader, once, at the root of `cpp/delimited/`:

- `delimited/Scanner.hpp` — the line scanner: splitting at the delimiter outside quotes, the
  header check, and exact integer, decimal, date and time of day reading
- `delimited/Values.hpp` — the values a row holds, and how a row prints them
- `delimited/Day.hpp` — the calendar: a day, and a time of day placed on it in its zone, by the
  C++20 time zone database

A reader includes them as `../delimited/`, which resolves with `cpp/delimited/delimited` on the
include path. `checks/` compiles each reader that way, and the programs under `executables/rows/`
read through them. Nothing here needs Arrow.
