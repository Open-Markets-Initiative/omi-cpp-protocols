# Verify Programs

Holds every packet in a capture to the binary rules it was framed by, through the Classes
library. Every check is read from the model's rules rather than written per protocol:

- the packet must decode
- each frame's length, as its header declares it, must be what the model reads (the size rule)
- each code must select the message that decoded, and never be one the specification does not
  list (the dispatch)
- the packet must encode back to exactly the bytes it was read from — encode derives the
  count, the lengths and the codes again, so the bytes agree only when every rule does

Packets are tallied by the kind their packet-level rules make them, and bytes after the last
frame are reported without failing. The first problems of each kind go to stderr with where
they lie; the tally and the verdict go to stdout. It exits 0 only when the whole capture
passes, 1 on any failure (a capture with nothing in it included), and 2 on a usage error.

```sh
./build/verify_<protocol> capture.pcap
```

Each protocol has its own directory, named for its identifier with the version as the last
segment — `Iex.IexEquities.Tops.IexTp.v1.64` becomes `iex/iexequities/tops/iextp/v1.64` —
matching the C++ namespace the code declares.

Each directory holds only the program: it includes its protocol's parser from `cpp/classes/`
and the capture reader from `executables/pcap/`, both resolved from the repository root, so
no program carries a copy of either.
