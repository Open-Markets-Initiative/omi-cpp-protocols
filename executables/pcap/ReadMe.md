# Capture Reader

The pcap reader every program and test shares. It is protocol-independent, so it is emitted
once here and put on their include path rather than copied beside each program.

- `PcapIterator.hpp` — walks the frames of one or more captures; `advance()` per frame
- `Frame.hpp` — dissects a frame down to its transport payload (Ethernet with VLAN tags,
  Linux cooked capture and raw IP; IPv4 and IPv6; UDP and TCP)
- `PcapSource.hpp`, `PcapFile.hpp`, `PcapBuffer.hpp`, `ZipPcapSource.hpp` — the sources a
  capture can be read from
- `TcpReassembler.hpp` — reassembles a TCP byte stream for length-prefixed protocols
- `decompressor/` — gzip, bzip2, lzma, lz4 and zstd, detected from the file

Compression support is optional: the build links zlib and zstd when it finds them.

```cpp
std::vector<std::pair<std::string, std::int64_t>> sources;
sources.emplace_back(path, 0);

packet::PcapIterator captures(sources);

while (captures.advance()) {
    const packet::Frame frame(captures.data(), captures.length());

    if (!frame.valid()) { continue; }

    // frame.payload, frame.payload_len
}
```
