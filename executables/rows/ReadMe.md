# Rows Programs

Reads a file of a protocol's lines, gzip or plain, through its reader: the header row selects the
layout variant, and each data line is read straight onto the protocol's plain C++ row (`Row.hpp`).
The first rows are printed as `name=value` (ten unless `--rows` says otherwise), every data line is
counted, and the lines that fail are reported. With `--day` each time of day counted from midnight
prints as the instant on that day, ISO 8601 UTC, rather than its count; a day that is not one is a
usage error.

```sh
./build/rows_<protocol> lines.csv.gz [--rows count] [--day yyyymmdd]
```

Each protocol has its own directory, named for its identifier with the version as the last
segment — `Iex.IexEquities.Tops.IexTp.v1.64` becomes `iex/iexequities/tops/iextp/v1.64` —
matching the C++ namespace the code declares.

Each directory holds only the program and what it alone needs: it includes its protocol's reader
from `cpp/delimited/` and the headers the readers share from `cpp/delimited/delimited/`, both on its include path
from the repository root, so no program carries a copy of either. Built where zlib is found; nothing needs Arrow.
