# Extractor Programs

Reduces a capture to a sample of each distinct message type — one small pcap per
discriminator value, plus a roll-up. Turning a day of traffic into a handful of frames that
still parse is what makes a capture usable as a test fixture.

```sh
./build/extractor_<protocol> capture.pcap output-directory
```

Writes `Sample.pcap` (one frame per message type), `MultipleMessages.pcap`, and a
`branch_<value>.pcap` for each discriminator value seen.

Each protocol has its own directory, named for its identifier with the version as the last
segment — `Iex.IexEquities.Tops.IexTp.v1.64` becomes `iex/iexequities/tops/iextp/v1.64` —
matching the C++ namespace the code declares.

Each directory holds only the program: it includes its protocol's parser from `cpp/modern/`
and the capture reader from `executables/pcap/`, both resolved from the repository root, so
no program carries a copy of either.
